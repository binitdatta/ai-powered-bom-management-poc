Platform Features

Everything needed to manage complex product specifications

Hierarchical BOM Management

3-level deep BOM hierarchy for the EdgeConnect Industrial IoT Gateway. Top-level products, major subassemblies, and sub-subassemblies all linked with parent-child relationships.

AI-Powered BOM Validation

LangGraph-orchestrated multi-step validation: obsolete component detection, high-risk supplier assessment, cost anomalies, lifecycle compliance — all in one chat prompt.

Keycloak 26 SSO

PKCE OAuth2 flow with role-based access (admin, engineer, viewer). Both the Spring Boot app and Flask ChatBot share the same bomiq Keycloak realm.

Rich REST API Layer

40+ endpoints for BOM CRUD, hierarchy traversal, cost summaries, validation payloads, component lifecycle queries, and supplier risk assessments. CORS-enabled for Flask client.

Excel Report Export

BOM validation reports downloadable as multi-tab Excel workbooks via openpyxl — header info, line items, compliance issues, supplier risks, all formatted for stakeholder review.

DBA-Owned Schema

Production-pattern MySQL 8: ddl-auto: validate, schema/seed SQL files, no H2, real constraints, indexes, and a dedicated app user with minimal privileges.

Architecture Overview

Two applications, one Keycloak realm, one MySQL database

Spring Boot 3.5.9 App (Port 9086)
  • Context path: /bomiq
  • Dual Spring Security chain: JWT for /api/**, OIDC session for UI
  • Thymeleaf + Bootstrap 5 light-blue UI
  • JPA + Hibernate with MySQL 8 (validate mode)
  • BOM/Component/Supplier/Product domain model
  • REST API endpoints at /api/v1/**
Python Flask ChatBot (Port 5000)
  • Keycloak PKCE auth via python-keycloak
  • LangGraph StateGraph for intent detection + multi-agent orchestration
  • Calls 4+ Spring Boot REST APIs per validation request
  • openpyxl for Excel workbook generation
  • SSE streaming responses to chat UI
  • Matching Bootstrap 5 light-blue theme
Keycloak 26 (Port 8080)
  • Realm: bomiq
  • Public PKCE client: bomiq-sdm
  • Roles: bomiq-admin, bomiq-engineer, bomiq-viewer
  • Back-channel logout support
  • Token introspection for Flask app
MySQL 8 (Port 3306)
  • Schema: bomiq_sdm
  • App user: bomiq_app (DML only, no DDL)
  • 9 tables: BOM hierarchy, components, suppliers, products, UOMs
  • 20 seeded BOMs: EdgeConnect IoT Gateway family
  • Full referential integrity with FK constraints
